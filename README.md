## Open source

- [Coding Agent Guidelines](https://github.com/incline-ltd/coding-agent-guidelines) gives Claude Code, Codex, Cursor, and other coding agents simple rules for small, verified changes.
- [Awesome Agentic Engineering](https://github.com/incline-ltd/awesome-agentic-engineering) curates useful tools and workflows for AI coding agents.
- [Agent Policy Map](https://github.com/incline-ltd/agent-policy-map) compares documented instruction discovery across Claude Code, Codex, Cursor, and GitHub Copilot.
- [Agent Cost Guard](https://github.com/incline-ltd/agent-cost-guard) adds a local approval gate for supported cloud-cost actions proposed by coding agents.
- [Production Launch Prompts](https://github.com/incline-ltd/production-launch-prompts) provides 21 practical audits for checking an app before real users arrive.
- [Awesome Agent Instructions](https://github.com/incline-ltd/awesome-agent-instructions) helps keep AGENTS.md, CLAUDE.md, rules, and skills lean with a sourced guide and a cleanup skill.
